# Réponses automatiques des boîtes contact@ (Hostinger)

Prêtes à installer avec l’API Hostinger (opération `mail_autoreplies_update`) : chaque fichier JSON contient
`autoreplyId`, `subject`, `body` (HTML) et `display_name`.

- `autoreply-dyro-studios.json` → contact@dyrostudios.com (commande mail OR5e0369ef05c5886fa907ce4257c4)
- `autoreply-dyro-web.json` → contact@dyroweb.online (commande mail OR441e9511dd8deb83b3036facb014)

Contenu : délai « devis sous 48 h », bouton Cal.com, prix courts hors TVA, ligne « Déjà client ? »,
signature d’équipe avec logo, résumé DE / EN (et PT pour DYRO WEB). Dossier `src/` : non publié sur le site.
